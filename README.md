# Política de Privacidad - Mi Bencina

La aplicación **Mi Bencina** es una herramienta gratuita diseñada para la comunidad. 

## Recolección de Datos
No recolectamos, almacenamos ni compartimos ningún tipo de dato personal del usuario.

## Ubicación
La app puede solicitar acceso a tu ubicación para mostrarte las estaciones de servicio más cercanas en Coronel, pero esta información se procesa localmente y no se guarda en servidores externos.

## Publicidad
Utilizamos Google AdMob para mostrar anuncios. Estos servicios pueden utilizar identificadores anónimos para ofrecer publicidad relevante.
